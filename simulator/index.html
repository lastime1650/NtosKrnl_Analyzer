YOUR FIRST VIRTUAL DRIVER

드라이버를 연결하고,
커널의 흐름을 살펴보세요.

  1. 노드를 추가합니다. 왼쪽 API / 자료형 / 흐름 노드를 캔버스로 끌어오세요.
  2. 핀을 연결합니다. 흰 실행 출력→입력, 색 데이터 출력→API 인자를 연결합니다. 핀을 순서대로 클릭해도 됩니다.
  3. 인자를 설정합니다. 우측 노드 패널에서 직접 값을 입력하거나 자료형 노드의 출력을 연결하세요.
  4. 디버깅합니다. Step Into(F11)·Step Over(F10)·Step Out(Shift+F11)을 사용하고, 노드 우클릭 메뉴로 중단점을 켜세요. EXPORT 안에서는 읽기 전용 실행 단계와 바이너리 CFG를 확인하세요.
  5. 실패를 수정합니다. BSOD 재시도 후 빨간 노드의 인자 / 연결을 변경하면 다시 실행할 수 있습니다.

풀 메모리는 실제 바이트 배열로 예약하고 해제합니다. 타이머는 가상 100ns 단위 시각으로 예약되며 DPC는 IRQL 2에서 실행됩니다. 가상 하드웨어는 BAR0 레지스터를 가진 교육용 주변 장치입니다.

API 계약 모델과 바이너리의 정적 호출 후보는 서로 구분됩니다. 정적 호출 후보는 실행 경로나 특정 BSOD 발생을 보증하지 않습니다. 자료형의 opaque 객체 저장소는 내부 필드 레이아웃을 재현하지 않으며, 직접 필드 접근이 필요하면 명시적인 사용자 구조체를 사용하세요.
