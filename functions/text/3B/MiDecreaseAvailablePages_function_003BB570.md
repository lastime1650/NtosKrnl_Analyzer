# MiDecreaseAvailablePages

- RVA: `0x003BB570`–`0x003BB582` (길이 `18` bytes)
- VA: `0x00000001403BB570`
- 실행 섹션: `.text`
- PDB 이름 있음: `예`; PDB Function 태그: `아니요`
- unwind 정보 RVA: `0x0008CC30`
- 디코드: `6`개 명령, `18/18` bytes 표시
- 미해석 바이트: `0` (있으면 어셈블리에 `.byte`로 보존)
