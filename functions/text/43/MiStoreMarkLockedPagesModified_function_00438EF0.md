# MiStoreMarkLockedPagesModified

- RVA: `0x00438EF0`–`0x00438EFC` (길이 `12` bytes)
- VA: `0x0000000140438EF0`
- 실행 섹션: `.text`
- PDB 이름 있음: `예`; PDB Function 태그: `아니요`
- unwind 정보 RVA: `0x000A37C0`
- 디코드: `4`개 명령, `12/12` bytes 표시
- 미해석 바이트: `0` (있으면 어셈블리에 `.byte`로 보존)
