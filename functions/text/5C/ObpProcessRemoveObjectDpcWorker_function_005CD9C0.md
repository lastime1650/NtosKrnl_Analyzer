# ObpProcessRemoveObjectDpcWorker

- RVA: `0x005CD9C0`–`0x005CD9D8` (길이 `24` bytes)
- VA: `0x00000001405CD9C0`
- 실행 섹션: `.text`
- PDB 이름 있음: `예`; PDB Function 태그: `아니요`
- unwind 정보 RVA: `0x0005C788`
