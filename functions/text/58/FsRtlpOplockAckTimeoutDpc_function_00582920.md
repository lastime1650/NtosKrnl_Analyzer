# FsRtlpOplockAckTimeoutDpc

- RVA: `0x00582920`–`0x0058293B` (길이 `27` bytes)
- VA: `0x0000000140582920`
- 실행 섹션: `.text`
- PDB 이름 있음: `예`; PDB Function 태그: `아니요`
- unwind 정보 RVA: `0x0005C788`
- 디코드: `7`개 명령, `27/27` bytes 표시
- 미해석 바이트: `0` (있으면 어셈블리에 `.byte`로 보존)
