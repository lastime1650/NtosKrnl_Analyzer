# sub_0041DE32

- RVA: `0x0041DE32`–`0x0041DE4F` (길이 `29` bytes)
- VA: `0x000000014041DE32`
- 실행 섹션: `.text`
- PDB 이름 있음: `아니요`; PDB Function 태그: `아니요`
- unwind 정보 RVA: `0x0009F9B0`
