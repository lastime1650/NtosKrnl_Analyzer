# sub_0041B1FF

- RVA: `0x0041B1FF`–`0x0041B204` (길이 `5` bytes)
- VA: `0x000000014041B1FF`
- 실행 섹션: `.text`
- PDB 이름 있음: `아니요`; PDB Function 태그: `아니요`
- unwind 정보 RVA: `0x0009D44C`
- 디코드: `1`개 명령, `5/5` bytes 표시
- 미해석 바이트: `0` (있으면 어셈블리에 `.byte`로 보존)
