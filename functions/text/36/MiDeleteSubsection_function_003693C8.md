# MiDeleteSubsection

- RVA: `0x003693C8`–`0x003693DF` (길이 `23` bytes)
- VA: `0x00000001403693C8`
- 실행 섹션: `.text`
- PDB 이름 있음: `예`; PDB Function 태그: `아니요`
- unwind 정보 RVA: `0x0005C788`
- 디코드: `8`개 명령, `23/23` bytes 표시
