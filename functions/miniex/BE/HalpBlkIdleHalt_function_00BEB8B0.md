# HalpBlkIdleHalt

- RVA: `0x00BEB8B0`–`0x00BEB8B5` (길이 `5` bytes)
- VA: `0x0000000140BEB8B0`
- 실행 섹션: `MINIEX`
- PDB 이름 있음: `예`; PDB Function 태그: `아니요`
- unwind 정보 RVA: `0x000BFB2C`
- 디코드: `5`개 명령, `5/5` bytes 표시
