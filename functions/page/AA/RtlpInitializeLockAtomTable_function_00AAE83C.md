- RVA: `0x00AAE83C`–`0x00AAE843` (길이 `7` bytes)
- VA: `0x0000000140AAE83C`
- 실행 섹션: `PAGE`
- PDB 이름 있음: `예`; PDB Function 태그: `아니요`
