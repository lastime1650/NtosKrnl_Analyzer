# PspIoMiniPacketCallbackRoutine

- RVA: `0x009F2240`–`0x009F2258` (길이 `24` bytes)
- VA: `0x00000001409F2240`
- 실행 섹션: `PAGE`
- PDB 이름 있음: `예`; PDB Function 태그: `아니요`
- unwind 정보 RVA: `0x0005C788`
- 디코드: `7`개 명령, `24/24` bytes 표시
- 미해석 바이트: `0` (있으면 어셈블리에 `.byte`로 보존)

> 이 문서는 커널 이미지의 기계어와 PDB 기호를 분석해 생성했습니다. 4번과 5번은 함수 원형과 자료형을 바이너리 사용 방식에서 추정한 C 해석이며 원본 소스 복구 결과는 아닙니다.

- RIP 상대 이미지 참조: **0**

- `0x009F224D` → [ObfDereferenceObject](../../text/2F/ObfDereferenceObject_function_002F9350.md) (function, `0x002F9350`)

### Direct callers

### Static image references
- 디코드된 RIP-relative 메모리 참조가 없습니다.
